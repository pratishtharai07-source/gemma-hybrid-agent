⚙️ Backend Configuration
When running on Vercel, this frontend needs to reach your local backend via a tunnel.
Use ngrok or Cloudflare Tunnel to expose port 8000.
How to get a tunnel URL:
• ngrok http 8000 → copy the https://xxx.ngrok.io URL
• cloudflared tunnel --url http://localhost:8000 → copy the URL
• Leave empty if accessing from the same machine as the backend.
